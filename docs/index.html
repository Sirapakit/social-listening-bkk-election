Features

Everything you need to track candidate buzz

From raw tweets to actionable sentiment — fully automated, cost-transparent.

🔍
Day-by-day idempotent scraping
Scrapes each day independently. Already-covered days are skipped automatically — re-running backfill never charges you twice.
💰
Real-time cost preview
Adjust the tweet cap with a slider and instantly see the realistic & maximum cost before pressing any button.
📅
Coverage calendar
Day-numbered badges show at a glance which days are complete, sampled (hit cap), or missing. One click to deep-scrape any day.
🤖
Thai + English sentiment
Custom lexicon classifier built on PyThaiNLP tokenizer with negation detection, intensifiers, and emoji weights — no PyTorch required.
⏰
Daily auto-scrape
APScheduler runs at configurable noon time every day. Zero manual effort once configured — the dashboard stays fresh automatically.
⚡
Fast local reads
All chart data served from SQLite — no Apify call on page load. Dashboard opens in <100ms even with months of history.

Quick Setup

Running in under 5 minutes

You'll need a free Apify account ($5 free credit) and Python 3.12+.

1
Clone & configure
Clone the repo and copy the environment template.
git clone https://github.com/Sirapakit/social-listening-bkk-election.git
cd social-listening-bkk-election
cp .env.example .env
# Edit .env — add your APIFY_API_TOKEN
2
Start the backend
Create a Python virtual environment and run FastAPI.
python3 -m venv backend/.venv
source backend/.venv/bin/activate
pip install -r backend/requirements.txt
cd backend && uvicorn main:app --reload --port 8000
3
Start the frontend
In a second terminal, install dependencies and run Next.js.
cd frontend
npm install
npm run dev
# Open http://localhost:3000
4
Backfill historical data
On first load the dashboard shows missing days. Click Backfill now — it scrapes day-by-day and skips any day already stored. Adjust the tweet cap slider to control cost.
